# Urban Chaos

This repository contains a community-maintained fork of the Urban Chaos source code.
The original code snapshot released by Mike Diskett had several issues that caused the game to malfunction on modern systems.
This fork includes multiple fixes, most notably resolving major graphics rendering problems, making the game playable again on current hardware.

## 
> **Note**: The project is still a work in progress. Ideally, the game should eventually be reworked to use a fully modern graphics API. For now, the goal is to restore playability and maintainability.

Different branches in this repository may contain experimental features, improvements, or breaking changes.
As a result, some versions may not be compatible with the original game data or levels.

If you would like to contribute — coding, testing, documentation, or research — please reach out.
At the moment this exists as a personal fork, but if more people become involved, it may evolve into a dedicated community project.
